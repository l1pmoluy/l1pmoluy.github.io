准备工作

安装

编译器*

编写frida用webstorm，下载一下，然后想要运行Js脚本的话还得下载一个nodejs

在对应项目目录下cmd然后输入

npm i @types/frida-gum

作用就是可以提示代码

firda server

想要将写好的frida脚本注入到进程中，就得用

frida server通过电脑链接手机，意味着电脑得开着

frida injectroot权限下，手机自己就直接注入了

frida gadget非root权限下手机自己注入

以上三个文件在frida github上下载

下载版本要与frida对应，下载之后解压出来的文件推送到手机的data/local/tmp目录下，然后赋予权限即可使用

ps:后台别关

frida版本问题

frida版本过高可能会导致一些软件不兼容，hook不进去

这边最推荐frida 16.0.19

pip install frida==16.0.19
